เปลี่ยนแพทย์

คู่มือการใช้งานระบบจัดตารางเวร

ระบบจัดตารางเวรนี้ใช้ Smart Solver สร้างตารางตั้งต้น 1 แบบ แล้วลองปรับอีก 300 แบบ ให้คะแนนทุกแบบ และเลือกแบบที่เท่าเทียมที่สุด ค่าสุ่มที่ใช้คำนวณมาจากข้อมูลที่กรอก ดังนั้นข้อมูลชุดเดิมจะได้ตารางเดิมทุกครั้ง ระบบรองรับเงื่อนไขดังนี้:

1. การจัดการแพทย์และบทบาท (Roles)

เพิ่มชื่อแพทย์และกำหนดบทบาทผ่านแท็กและเมนูเลือก ระบบจะจัดเวรแยกตามกลุ่มบทบาทของแต่ละวัน หากต้องการกำหนดโควตาที่จำนวนไม่พอดีกับช่องเวร ให้เปิดใช้งาน Allow Blank Days เมื่อลบแพทย์ออก ชื่อนั้นจะถูกลบออกจากการล็อกเวรพิเศษ วันขอหยุด และการแก้ไขตารางด้วย

2. จำนวนเวรตามบทบาท (Slots)

กำหนดจำนวนผู้ปฏิบัติงานต่อวันด้วยปุ่มเพิ่ม/ลด (Stepper) และปรับเฉพาะบางวันได้ใน 'กำหนดพิเศษ' คุณยังล็อกแพทย์ให้อยู่เวรวันใดวันหนึ่งได้ แพทย์ที่ถูกล็อกต้องผ่านกฎเดียวกับคนอื่น ทั้งความขัดแย้ง ระยะพักเวร วันหยุดติดกัน และวันก่อนวันหยุดขอ หากวันนั้นอยู่เวรไม่ได้ ระบบจะจัดคนอื่นแทนตามปกติ
'ขั้นต่ำเวรต่อคน' (ค่าเริ่มต้น 14, ใส่ 0 เพื่อปิด, สูงสุด 60) รับประกันว่าแพทย์ทุกคนได้เวรไม่น้อยกว่าค่านี้ เมื่อเปิด 'อนุญาตแพทย์เสริมในเวรดึก' ระบบจะเพิ่มแพทย์เสริมได้ไม่เกิน 1 คนต่อคืน เฉพาะในจำนวนคืนที่จำเป็น กระจายทั่วเดือน และแบ่งตามความต้องการของแต่ละบทบาท เหนือตารางจะมีบันทึกแผนในรูป 'N ช่อง + M แพทย์เสริม = จำนวนเวรรวม → X เวร/คน' หากปฏิทินมีช่องไม่พอ (เช่น ต้องใช้ 70 เวร แต่มีได้ 60) หรือแพทย์หรือบทบาทใดไปไม่ถึงขั้นต่ำ ระบบจะปฏิเสธการจัดและบอกเหตุผล ขั้นต่ำนี้ใช้กับตารางแบบปกติ แบบแยกบทบาท และแบบผลัดที่ไม่แยกบทบาท ส่วนแบบบทบาท+ผลัดและแบบโควตาจะใช้ตัวจัดเวรแบบเดิมและแสดงข้อความเตือน

3. แพทย์ที่ขัดแย้งกัน (Conflict List)

เลือกคู่แพทย์ที่ไม่ควรอยู่เวรด้วยกันผ่านเมนูเลือก ระบบจะไม่จัดสองคนนี้ในวันเดียวกันเมื่อมีแพทย์เพียงพอ หากปิด Allow Blank Days และไม่มีใครว่างแล้ว ระบบอาจยอมให้คู่นี้อยู่วันเดียวกันเพื่อให้ช่องเวรไม่ว่าง โดยบันทึกไว้ในแผงเตือนและแสดงป้ายเตือน การแก้ตารางด้วยตนเองจนเกิดการชนกันก็แสดงป้ายเตือนเช่นกัน

4. วันหยุดและวันพัก (Off Requests)

ระบบจัดเวรหลีกเลี่ยงวันที่ขอหยุด วันก่อนวันขอหยุด วันหยุดติดกัน และเว้นระยะพักเวรตามที่ตั้งไว้ เมื่อมีแพทย์เพียงพอ ระยะพักเวรนับจาก 0: 0 = ไม่เว้น, 1 = เว้น 1 วันหลังอยู่เวร ไฟล์ที่ส่งออกไว้ก่อนหน้านี้จะถูกแปลงให้อัตโนมัติ หากปิด Allow Blank Days และไม่มีใครว่างแล้ว ระบบอาจลดวันหยุดติดกัน หรือวันก่อนวันขอหยุดลง และลดระยะพักเวรได้เฉพาะเมื่อตั้งขั้นต่ำเวรต่อคนเป็น 0 เพื่อให้ช่องเวรไม่ว่าง แต่จะไม่จัดแพทย์ลงในวันที่ขอหยุดจริง ทุกครั้งที่ผ่อนปรนจะถูกหักคะแนนและแสดงรายวันในแผง "เงื่อนไขที่ต้องผ่อนปรน" พร้อมจำนวนในข้อความแจ้งสำเร็จ เมื่อใช้ขั้นต่ำเวรต่อคน (มากกว่า 0) ระบบจะไม่ลดระยะพักเวรเลย หากช่องใดเติมไม่ได้โดยไม่ผิดกฎนี้ ระบบจะปฏิเสธและบอกวันที่ติดปัญหา กรอกวันขอหยุดได้เป็นวันเดียว เช่น 5 เป็นรายการ เช่น 3,7 หรือเป็นช่วง เช่น 2-5 ในโหมดช่วงวันที่กำหนดเองให้กรอก 25/02/2026-04/03/2026 ระบบจะเตือนเมื่อการแก้ตารางไปชนวันขอหยุด ทั้งแบบช่วง แบบรายการ และวันที่ในช่วงกำหนดเอง

5. การแก้ไข ย้อนกลับ และตรวจสอบตาราง

ลากและวาง (Drag & Drop) ชื่อแพทย์ในตาราง ปฏิทิน และมุมมองบุคคลเพื่อสลับตัวด้วยตนเอง หรือเลือกจากเมนูและแผ่นเลือกบนมือถือ ทุกการแก้ไข (รวมถึงรีเซ็ตกลับเป็นค่าอัตโนมัติ) จะถูกตรวจก่อนบันทึก ได้แก่ ชื่อซ้ำ คู่ขัดแย้ง บทบาท วันขอหยุด ระยะพักเวร วันหยุดติดกัน เวรดึกต่อเช้า โควตา และขั้นต่ำเวรต่อคน หากผิดกฎ ระบบจะไม่เปลี่ยนตารางและแจ้งเหตุผลในข้อความ การลากสลับจะตรวจผลลัพธ์สุดท้ายของทั้งการสลับ เมื่อสร้างตารางใหม่ นำเข้าไฟล์ หรือย้อนกลับ ระบบจะตรวจการแก้ไขเก่าอีกครั้ง รายการที่ใช้ไม่ได้แล้วจะถูกตัดออกพร้อมข้อความเดียว แผง "เงื่อนไขที่ต้องผ่อนปรน" เหนือตารางแสดงเฉพาะกฎที่ผ่อนปรนในการจัดอัตโนมัติ สถิติและป้ายเตือนอัปเดตทันที กดปุ่มย้อนกลับ (Undo) ที่แถบเครื่องมือเหนือตาราง (ปรากฏหลังแก้ไข) หรือ Ctrl+Z เพื่อย้อนการแก้ไขทั้งหมด รวมถึงการสลับด้วยการลาก (ถ้าเคอร์เซอร์อยู่ในช่องพิมพ์ Ctrl+Z จะย้อนข้อความตามปกติ) เมื่อเปลี่ยนเดือน ปี หรือช่วงวันที่ การแก้ไขด้วยตนเองจะถูกล้างอัตโนมัติและมีข้อความแจ้งเตือน ส่วนการลบแพทย์ (เช่น ด้วย Backspace) ไม่สามารถย้อนกลับได้

6. การบันทึก/โหลดและการใช้งานออฟไลน์

ส่งออกการตั้งค่าทั้งหมดเป็นไฟล์ JSON เพื่อนำกลับมาใช้ใหม่ได้ ไฟล์ที่ส่งออกมีเลขเวอร์ชันของการตั้งค่า ไฟล์เก่าที่ใช้ระยะพักเวรแบบนับจาก 1 จะถูกลดลง 1 ให้อัตโนมัติ หากไฟล์ที่นำเข้าอ่านไม่ได้ ระบบจะปฏิเสธไฟล์และคงการตั้งค่าเดิมไว้ ชื่อแพทย์จะถูกจัดให้เรียบร้อย คือตัดช่องว่างหน้าหลัง ลบชื่อซ้ำ และแทนที่อักขระ : ; , / ด้วยช่องว่าง หากเดือนหรือปีไม่ถูกต้อง ระบบจะแจ้งข้อความแทนการสร้างตารางที่ผิด เมื่อโหลดหน้าเว็บครั้งแรกแล้ว แอปใช้งานแบบออฟไลน์ได้ และจะอัปเดตตัวเองอัตโนมัติเมื่อมีเวอร์ชันใหม่

7. โหมดช่วงวันที่กำหนดเอง (Custom Date Range)

เปิด 'ใช้ช่วงวันที่กำหนดเอง' เพื่อจัดเวรตามวันที่ต้องการ (สูงสุด 90 วัน) แทนการจัดตามเดือน โดยกรอกวันที่ในรูปแบบ DD/MM/YYYY วันขอหยุดในโหมดนี้กรอกเป็นวันที่เต็ม เช่น 25/02/2026 หรือเป็นช่วงได้ การกำหนดจำนวนคนเฉพาะวันจับคู่ด้วยวันที่เต็ม (เช่น 2026-02-25 หรือ 25/02/2026) หรือเลขวัน ระบบไม่รับวันที่ที่ไม่มีจริง (เช่น 31/02) และวันเริ่มต้องอยู่ก่อนวันสิ้นสุด
การต่อเนื่องระหว่างช่วง: หากจัดช่วงถัดไปที่ต่อติดกับตารางปัจจุบันพอดี (เช่น เดือนถัดไป) ระบบจะนำเวรท้ายช่วงของแพทย์แต่ละคน รวมถึงที่แก้ด้วยมือ มาคิดในวันแรก ทั้งระยะพัก เวรดึกต่อเช้า และวันหยุดติดกัน หากช่วงไม่ต่อกันหรือรายชื่อแพทย์เปลี่ยน ระบบจะไม่นำมาคิด

8. โหมดจัดเวร 3 ผลัด (Shift-Based Mode)

จัดเวร 3 ผลัดต่อวัน (เช้า บ่าย ดึก) และกำหนดจำนวนคนของแต่ละผลัดได้อิสระ ห้ามอยู่เวรเช้าต่อจากเวรดึก และห้ามอยู่เวรดึกในวันก่อนวันขอหยุดเท่านั้น (เวรเช้าและบ่ายยังจัดได้) สถิติสรุปจะแยกตามผลัด

9. หน้าจอ แถบความเท่าเทียม และส่งออกปฏิทิน

บนจอแล็ปท็อปและ iPad แนวนอน (กว้างตั้งแต่ 1024px) การตั้งค่าอยู่คอลัมน์ซ้ายที่เลื่อนแยกได้ และตารางอยู่ด้านขวา ส่วน 'จำนวนแพทย์ต่อวัน' และ 'กฎขั้นสูง' พับเก็บได้ บนจอเล็กกว่านั้น กดปุ่ม 'ตั้งค่า' ที่ส่วนหัวเพื่อเปิดแผงเลื่อนเข้ามา แตะนอกแผงหรือกด Esc เพื่อปิด และบนมือถือแต่ละแถวของตารางจะแสดงเป็นการ์ด
แถบความเท่าเทียมเหนือตารางแสดงจำนวนเวรรวมของแพทย์แต่ละคน คนที่ห่างจากค่าเฉลี่ยมากที่สุดจะมีกรอบสีเหลืองอำพัน และส่วนต่างสูงสุดแสดงทางขวา ตารางเต็มอยู่ใน 'รายละเอียดรายบุคคล' ซึ่งเปิดไว้ตั้งแต่แรก
ส่งออกปฏิทินได้ทั้งหมด เฉพาะบทบาท หรือรายบุคคล 'Apple Calendar' จะดาวน์โหลดไฟล์ .ics ส่วน 'Google Calendar' จะดาวน์โหลดไฟล์แล้วเปิดหน้านำเข้าของ Google ให้คุณนำเข้าไฟล์เอง หากป๊อปอัปถูกบล็อก จะแสดงลิงก์ให้แทน การนำเข้าซ้ำจะเพิ่มกิจกรรมใหม่แต่ไม่ลบกิจกรรมเก่า
